# Choose Your Path

Once you understand ROS 2 basics (Part 1) and how A2Bot is built (Part 2), Part 3 splits by which machine you're setting up.

## Setup 1: Raspberry Pi

Choose this if you have a **bare Raspberry Pi and bare chassis** — nothing assembled or configured yet. Setup 1 walks through flashing the Pi's OS, wiring the electronics, flashing the Arduino, installing ROS 2 and the A2Bot workspace, and configuring networking, in the order it actually needs to happen.

Go to: [Setup 1 — Raspberry Pi](../part3/setup-1-raspberry-pi.md)

## Setup 2: Laptop

Choose this if you're in a classroom or workshop where **a robot is already built and running**, and you just need your laptop set up to talk to it — install ROS 2, connect to the network, and confirm you can see the robot's topics. This is also the page you continue to after finishing Setup 1.

Go to: [Setup 2 — Laptop](../part3/setup-2-laptop.md)

## After setup

Both routes converge on the same rest-of-the-site content: [Bringup & Driving](../part3/bringup-and-driving.md), [SLAM & Navigation](../part3/slam-and-navigation.md), and the [Capstone](../part3/capstone.md) project all work the same regardless of which route got you there.

!!! tip
    Not sure which applies? If you never had to plug a USB cable into an Arduino or wire a motor, you're almost certainly a Setup 2 (Laptop) only reader.
